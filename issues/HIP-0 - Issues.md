# HIP-0 - Issues
HIP (Henka Issue Prompt) documents describe bugs and features concisely.


## Naming
```
HIP-[number] - [title].md
```

One issue per file. Saved in `issues/`.


## Status
- **Open** — not yet started
- **WIP** — in progress
- **Closed** — resolved


## Bug
```markdown
# HIP-N - Title
**Status:** Open


## Bug
What is broken and how to reproduce it.


## Fix
What needs to change to resolve it.
```


## Feature
```markdown
# HIP-N - Title
**Status:** Open


## Problem (or Requirement)
What is missing or needed and why.


## Solution
What should be built or changed.
```

Both types may include additional subsections (e.g. Notes, Constraints, References) when necessary. Keep entries short and prompt-like.

References between HIPs should be links.
